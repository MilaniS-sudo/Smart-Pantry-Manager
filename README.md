# Smart Pantry Manager

A Java Android application developed for Richfield Mobile App Development 700.

## Project Overview

Smart Pantry Manager helps users reduce food waste by tracking pantry ingredients and suggesting recipes only when every required ingredient is already available.

## Planned Features

- Add pantry ingredients
- Edit and delete ingredients
- RecyclerView pantry list
- SQLite database
- 15–20 preloaded recipes
- Strict recipe matching
- Recipe details screen
- Settings screen

## Technology

- Java
- Android Studio
- SQLite
- RecyclerView
